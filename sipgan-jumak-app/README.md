# 십간주막 — React 프로토타입

기획 문서 v0.7 기반 MVP 구현입니다. 생년월일→일간 계산, 취향(T1~T4)·상황(S1~S4) 질문,
v0.7 통합 축 가중치 알고리즘(z-score 정규화, 사주 목표 비중 33%, diversify, 동률 로테이션)까지
전체 플로우가 실제로 동작합니다.

## 실행

```bash
npm install
npm run dev       # http://localhost:5173
npm run build      # 프로덕션 빌드
```

## 구조

```
src/
  data/
    liquors.json        # 120종 전통주 (원시축10 + 파생축5 + 태그/메타)
    tengan.json          # 십천간 10개 프로필
  lib/
    types.ts             # 공용 타입
    tengan.ts             # 일간(日干) 계산 — lunar-javascript 사용 (기획 07 리스크 항목 반영)
    algorithm.ts          # v0.7 추천 알고리즘 (z-score, scale=0.5 비율, diversify, 동률 로테이션)
  App.tsx                # 질문 흐름 + 결과 화면
  App.css                # 기획 문서 톤앤매너(paper/ink/accent) 반영 스타일
```

## 알고리즘 요약 (기획서 05 참고)

- 15개 통합 캐릭터 축(원시10+파생5)에 취향·상황·사주가 각각 +/- 가중치를 투영합니다.
- 축 값은 120종 풀 기준 z-score로 정규화한 뒤 가중 평균(alignment)을 계산합니다.
- B(십천간 가중 추천)의 사주 비중은 `scale = 0.5 × Σ|취향+상황| / Σ|사주_raw|`로,
  취향·상황 신호 크기에 비례해 항상 약 33%를 유지합니다.
- 안주 카테고리 매칭 가산점(0~30), 구매접근성 보정(A:+10/C:-5)을 더해 최종 점수를 만들고,
  대분류 다양성 보정(diversify)과 동률 로테이션을 거쳐 top-3를 뽑습니다.

## 알려진 한계 / 다음 단계 (기획서 08 참고)

- **일간 계산 검증**: `lunar-javascript`를 사용했지만, 알려진 생일 10~20건 수기 대조는 아직
  하지 않았습니다. 프로덕션 전 필수 검증 항목입니다.
- **scale=0.5(사주 비중 33%)**: 가정한 응답 분포 기반 시뮬레이션 값이며, 실제 사용자
  데이터로 재검증이 필요합니다.
- **청량감 축 편중**: S1(혼술·모임·파티)이 여전히 청량감 축을 공유해 일부 케이스에서
  천간별 차별화가 약합니다(기획서 08의 07번 항목).
- **DB 재검증**: 120종 중 77종이 "MVP 후보" 상태로, 정식 출시 전 개별 재확인이 필요합니다.
- UI는 기능 검증 목적의 최소 스타일입니다. 진행 표시줄, 이전 답변 수정, 반응형 다듬기,
  B·C 교차 하이라이트 배지 등은 아직 없습니다.
